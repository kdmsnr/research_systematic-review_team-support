# Systematic Review of Support for Product Development Teams

This repository hosts the protocol for *What Practitioners Notice and How They Interpret It When Supporting Product Development Teams*, a qualitative systematic review.

[Read the protocol](protocol/protocol.md) — version 1.0.1, dated 22 October 2026. It specifies the research questions, eligibility criteria, complete search strategies, AI-assisted assessment of all title-and-abstract records, human validation and exclusion audits, human full-text eligibility decisions, source-verified extraction, methodological appraisal, thematic synthesis and confidence assessment.

Supplementary materials will be added only when required by reporting guidelines or the target journal.
